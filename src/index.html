About

I'm a software engineer with 7+ years designing and delivering systems in demanding environments — aeronautics, automotive, industrial R&D. What drives me isn't a specific stack or domain, it's the full journey: understanding a real need, shaping it into something buildable, architecting it properly, and seeing it through to a system running in production.

That process — understand, specify, architect, build, deploy — stays consistent across domains. What changes is the execution: a real-time embedded system isn't tested, validated, or deployed the same way as a web platform.

Approach

Every project follows the same shape, regardless of domain: understand the real need, specify it clearly, architect it to last, then build and deploy it in stages rather than all at once.

  • Stakeholder interviews & needs analysis
  • Identifying the real problem behind the request
  • Technical, regulatory and business constraints mapping

  • Requirements & specification writing
  • Functional and technical scoping
  • Feasibility assessment and trade-off analysis

  • Software & system architecture design
  • Technology and tooling selection
  • Designing for scalability, maintainability, robustness

  • Proof of concept development
  • De-risking the hardest unknowns early
  • Fast iteration and validation with real constraints

  • Incremental development pipeline
  • Continuous testing at every stage, not just at the end
  • Code quality, review discipline, documentation as you go

  • Production deployment
  • Handover documentation for long-term maintainability
  • Post-deployment support and monitoring
