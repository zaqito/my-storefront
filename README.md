# Expertise Website

## Description

Site vitrine professionnel destiné à présenter une activité indépendante d'ingénieur logiciel.

L'objectif est de construire une présence web durable permettant de présenter une expertise technique, une approche de travail et des réalisations concrètes auprès de futurs clients, partenaires ou recruteurs.

Le site n'est pas un CV en ligne mais une vitrine d'expertise.

## Objectifs principaux

* Présenter une expertise en conception et développement de solutions logicielles complexes.
* Montrer une capacité à comprendre un besoin métier ou technique et proposer une solution adaptée.
* Valoriser une approche d'ingénierie : qualité, architecture, maintenabilité et fiabilité.
* Préparer progressivement une activité freelance.

## Principes

* Pas de liste de technologies sans contexte.
* Mettre en avant les problèmes résolus plutôt que les outils utilisés.
* Construire un site simple, performant et maintenable.
* Aucun travail temporaire ou jetable.
* Chaque élément produit doit pouvoir évoluer vers la version finale.
