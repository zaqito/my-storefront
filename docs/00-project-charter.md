# Project Charter

## 1. Vision du projet

Créer une vitrine web professionnelle présentant une activité d'ingénieur logiciel indépendant.

Le site doit transmettre une image :

* technique ;
* fiable ;
* professionnelle ;
* orientée résolution de problèmes.

L'objectif n'est pas de vendre une expertise technologique mais une capacité à concevoir des solutions adaptées.


## 2. Public cible

Priorité :

* futurs clients freelance ;
* responsables techniques ;
* responsables R&D ;
* recruteurs spécialisés.


## 3. Positionnement

Positionnement initial :

> Ingénieur logiciel spécialisé dans la conception et le développement de solutions complexes.

Le positionnement devra rester suffisamment large pour couvrir :

* logiciels internes ;
* outils métiers ;
* applications techniques ;
* systèmes temps réel ;
* vision et traitement d'image ;
* intégration de solutions complètes.


## 4. Identité souhaitée

Le site doit représenter une marque professionnelle discrète.

Choix validés :

* pas de photo personnelle ;
* pas de personal branding fort ;
* identité sobre et évolutive.


## 5. Contraintes

Le site doit être :

* statique ;
* rapide ;
* bilingue FR/EN ;
* responsive ;
* accessible ;
* facilement maintenable.

Exclusions :

* CMS ;
* blog ;
* back-office ;
* base de données ;
* animations complexes.


## 6. Critère de réussite

Le visiteur doit comprendre rapidement :

1. Qui propose le service.
2. Quels problèmes peuvent être résolus.
3. Quelle approche est utilisée.
4. Quelles expériences démontrent la crédibilité.
5. Comment prendre contact.
