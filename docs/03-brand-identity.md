# Brand Identity

## Direction générale

Identité visuelle :

* sobre ;
* premium ;
* technique ;
* orientée ingénierie.

Références :

* Linear ;
* Vercel ;
* JetBrains.

## Positionnement visuel

Éviter :

* style startup marketing ;
* surcharge graphique ;
* effets visuels démonstratifs.

Privilégier :

* clarté ;
* précision ;
* espaces ;
* hiérarchie visuelle.

## Palette

Direction initiale :

* fond gris très sombre neutre ;
* accent orange doux ;
* contrastes élevés.

La palette sera affinée dans le Design System.

## Typographie

Objectifs :

* lisibilité ;
* aspect professionnel ;
* confort sur mobile.

Options envisagées :

* Inter ;
* Atkinson Hyperlegible.

## Interface

Principes :

* cartes sobres ;
* arrondis modérés ;
* animations discrètes ;
* composants simples.

Le design doit refléter une approche d'ingénieur :
fonctionnel, précis et durable.
